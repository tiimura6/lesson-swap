# 合同化（別クラスの授業に合流）設計

## ねらい
先生が不在のコマを空けるため、単独の授業を、別クラスの同じ科目の授業に合流させて合同にする候補を出す。今ある「合同授業の一括交換」は、すでに合同の授業を動かす機能で、これとは別物。

## やること
- 授業・時間割タブの中に3つ目の画面「合同化」を作る（授業交換／クラス別時間割／合同化）。`GROUP` に `merge: 'tt'` を足す。
- 入力：教員A → その先生の単独授業（コマ）を選ぶ。
- 出力：合流できる候補の一覧。

## 判定
自分の授業 me（クラスK・科目S・教員A・コマP）について：

1. **同じコマで合流（パターン1）**：コマPに、同じ学年・同じ科目名・同じ文理（高校2年以上）で別クラスの授業 o（教員B）がある → Kが o に合流。ほかは動かない。
2. **別のコマへ移って合流（パターン2・主）**：コマYに同条件の授業 o がある。KがYにもともと受けている授業 q（教員C）をコマPへ移す。条件：
   - C（q の担当者全員）がコマPで空いている
   - q が合同授業（複数クラス）なら候補にしない（連鎖が大きくなるため）
   - Y = P は1で扱う
3. 結果：Aは P（と、AがYでKを持っていればY）が空く。

## 表示（各候補）
- 合流先：o の授業・担当者・コマ
- 移す授業：q ➔ コマP（パターン1は「移動なし」）
- 警告：研修・会議（`hasAnyEvent`）、非常勤（`isParttimeTeacher`）、情報教室の重なり（`infoRoomConflict`）は今の交換画面と同じ色分け
- すべての候補に「進度・教科書・教室の定員を確認」と添える（選択科目・習熟度別は時間割データで見分けられない）
- 並び順：パターン1 → 警告なし → 警告あり

## 印刷・保存
- 先生の決定：授業交換の印刷カートとは**別にする**。
- 合同化画面に専用の選択（チェック欄）と「印刷」ボタンを持つ。印刷は選んだ候補だけを、今の交換の印刷と同じ体裁（コマ・クラス・合流先・移す授業・担当者）で出す。
- 今の `printCart`・`ttPrintCart`・「保存した記録」の形式には触れない。（私の判断：合同化の選択は「保存した記録」には入れない。必要なら後で種類を追加する）

## しないこと
- 今の授業交換画面の判定・表示は変えない
- 3クラス以上の合同化、合同授業 q の連鎖移動
- 教室の定員データの導入

## 作り方の比較（決定：B）
- A 授業交換の結果に追加：警告・印刷を流用できるが一覧が長くなる
- **B 別画面（採用）**：既存機能を壊しにくい。判定の部品（`teacherHasSlot` など）は共有し、画面だけ新しく作る
- C 交換が無いときだけ表示：合同のほうが楽な場合が見えない
