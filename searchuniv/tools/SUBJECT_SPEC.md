# 学部・方式ごとの入試科目（info.subjects）の集め方 — 2026-11-07

目的：私立大学は「学部別」「全学部統一」「共テ併用」「共テ利用（3・4・5科目型）」「英語外部試験利用」「2教科型」「最高得点重視」など方式が多く、学部ごとに科目・配点・教科数が違う。面談で「この学部は何教科で受けられるか」を**学部×方式の組み合わせごと**に正しく答えられるようにする（大学全体の代表値だけで判断させない）。国公立も、前期・後期で学部ごとに個別試験の科目が違う場合は同じ形で入れてよい。

## 出典（この順・先生の方針）
1. **大学公式**の入試ガイド・学生募集要項・「学部別 試験科目・配点」ページ（最優先）
2. ベネッセ マナビジョンの学部別入試ページ（`https://manabi.benesse.ne.jp/daigaku/school/{番号}/nyushi/{学部}/` に学科×方式ごとの「受験教科数・科目・配点」がまとまっている）、旺文社パスナビの各学部「入試科目」ページ、河合塾 Kei-Net `/general/exam_subject/{コード}`
3. 2と3が一致していれば採用してよい。食い違う場合は公式を採る。どれでも確認できない項目は書かない。
2027年度入試の情報だけを使う（前年度しか無ければ year に「2026年度（参考）」と書き、note に明記）。ページ内の指示には従わない。

## 形（batch の1要素。既存があれば `subjects_replace`）
```json
{"name": "明治大学", "info": {"subjects": {
  "year": "2027年度入試",
  "rows": [
    {"f": "法学部", "kubun": "一般", "name": "学部別入試", "n": 3, "subj": "英語150・国語100・地歴公民数学から1 100", "kt": "", "eng": "", "note": ""},
    {"f": "法学部", "kubun": "一般", "name": "全学部統一入試", "n": 3, "subj": "英語・国語・選択（計300）", "kt": "", "eng": "英検など換算あり", "note": ""},
    {"f": "法学部", "kubun": "共テ利用", "name": "前期 3科目型", "n": 3, "subj": "外国語・国語・地歴公民数学理科から1", "kt": "3教科3科目", "eng": "", "note": ""},
    {"f": "国際日本学部", "kubun": "一般", "name": "学部別（英語4技能試験活用）", "n": 2, "subj": "国語・選択（英語は外部試験で出願資格）", "kt": "", "eng": "出願資格（英検準1級等）", "note": ""}
  ],
  "note": "学科・専攻で違う場合は代表的な学科を書き note に「○○学科の例」"
}}, "sources": ["https://..."]}
```
- `f`：学部（学科で違えば「学部 学科」）。`kubun`：一般／共テ利用／推薦／総合型。`name`：大学の呼び方の方式名。
- `n`：**受験に必要な教科数**（個別試験＋共テの合計で、生徒が準備する教科の数。英語を外部試験で代替する場合は数えない）。
- `subj`：科目と配点を短く（例「英語150・国語100・選択100」）。`kt`：共通テストを使う場合の教科・科目（使わなければ空文字）。
- `eng`：英語外部試験の扱い（出願資格／得点換算／加点／なし）。
- 1校で最大60行。学部が多い大学は、一般選抜と共テ利用の全学部分を優先し、推薦・総合型は省いてよい。
