# この大学を選ぶ理由（ストーリー）— guide.story（2026-11-11 先生の依頼）

生徒に大学を提案するときに「その大学のストーリー」を語れるように、**どうして他の大学ではなくこの大学なのか**を出典つきで集める。
画面では「指導のポイント」に「この大学のストーリー」「ここだけの点」「他校との違い」として出る（その下に、登録データを自動で比べた「比べられやすい学校」「ここを選ぶ理由」「他校のほうが合う場合」も出る）。進路面談のおすすめにも「ここを選ぶ理由」として1〜2点出る。

## batch の形（既存校は name と story だけでよい。story は丸ごと置き換わる）
```json
{"name": "金沢大学",
 "story": {
   "summary": "2〜3文。何を・どんな環境で学び・卒業後どこへ進むかの筋道を、出典で確かめた事実だけでつなぐ。",
   "only": [ {"t": "ここだけの点（1文）", "src": "https://（大学公式など）"} ],
   "vs":   [ {"u": "比べる相手の大学名（一覧の正式名）", "t": "相手校と比べた違い（1文）", "src": "https://…"} ]
 }}
```
- **only（2〜4件）**：大学公式（なければ文部科学省・Kei-Net・パスナビ）が明記している、その大学ならではの事実。例：国内で唯一・国内初の学部や学科、全員必修の留学、独自の教育制度（学部をまたぐ専攻、入学後に専門を選ぶ仕組み、少人数ゼミの必修）、附属病院・演習林・練習船などの施設、地域枠・寮制度、取れる資格の組み合わせ。**「唯一」「初」「最大」は出典がそう書いているときだけ**使う。
- **vs（1〜3件）**：画面の「比べられやすい学校」（同じ分野・偏差値帯が近い・同じ地方を優先。`whyRivals()`）から選び、学べる分野・教育制度・費用・入試方式・立地などの違いを書く。相手校の側の事実も出典で確かめる（data/info.json にあればその出典URLでよい）。相手を下げる書き方はしない（「Aは〜だが、この大学は〜」の形）。
- **summary**：only と vs をふまえて、担任が生徒に話せる2〜3文。「最高」「必ず」「一流」などの評価語・断定は使わない。
- src の無い項目は merge_batch.py が捨てる。出典で確かめられなければ書かない（空なら story ごと入れない）。
