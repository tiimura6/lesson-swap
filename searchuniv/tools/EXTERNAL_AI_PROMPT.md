# 他のAIに大学情報を集めてもらうためのプロンプト（2026-11-07）

使い方
1. 下の「プロンプト本文」をそのままコピーし、他のAI（Web検索ができるもの：ChatGPT の検索・Deep Research、Gemini、Perplexity など）に貼る。
2. `{{ここに大学の一覧}}` を、`tools/external_todo.md` の「依頼1」などの一覧（10校ずつ）に置き換える。
3. AIが返した JSON を、そのまま Claude に貼るか、`batches/external_日付.json` として保存して渡す。
4. Claude が `python3 tools/check_external.py <ファイル>` で形式と出典を確かめてから取り込む。取り込んだデータは「外部AI」と印を付け、毎時の自動収集が大学公式で裏取りする（PIPELINE.md の「外部AIのデータの裏取り」）。

注意：他のAIは、出典を確かめずに数字を作ることがあります。出典URLの無い項目は取り込みません。

## プロンプト本文（ここから下をコピー）

あなたは日本の大学入試の調査担当です。高校3年生の進路指導に使うデータベースのために、下の大学それぞれについて、**Webで確認できた事実だけ**を集め、指定の JSON で返してください。

### 守ること
- 出典は **①大学公式サイト（入試ガイド・学生募集要項・学費ページ）を最優先**、次に ②旺文社パスナビ・河合塾Kei-Net・ベネッセ マナビジョン。①と②が食い違えば①を採る。
- **2027年度入試（2026年度に実施）の情報**を使う。まだ出ていない項目は前年度を使わず `null` にする（学費だけは2026年度でよい。その場合 year に「2026年度」）。
- 推測・記憶で埋めない。確認できない項目は `null` または空の配列 `[]`。
- 各大学の `sources` に、使ったページのURLをすべて入れる。項目ごとの出典が分かるよう、`src` を付けられる項目には付ける。
- **一般の高校生が出願できない学校（大学院だけの大学、職員の研修機関など）は調べずに** `{"name": "…", "skip": "理由"}` だけ返す。
- 文章は自分の言葉で短く（丸写ししない）。
- 出力は **JSON の配列だけ**（前後に説明文を付けない）。
